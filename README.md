# Rheumatoid Arthritis epidemiology project

In this project, I used [data](https://sources.healthdata.org/collection/sources-2023?components=5&causes=627&impairments=0&locations=1) from the Institute of Health Metrics and Evaluation (IHME) about the Global Disease Burden (GBD). I downloaded the global non-fatal health outcomes csv to find studies of specifically RA. Then I mapped the location onto a world map to be able to group the studies. I want to know, if I can find any North-South-axis in the disease prevalence and if there is an association between prevalence and maritime climate.
